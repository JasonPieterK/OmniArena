Setup in 3 steps
About five minutes. No config files.
3
1
Setup
/oa setup duel_1
Creates the arena, gives you the wand, opens the setup menu.
Left-click one corner, right-click the opposite one.
/oa setup duel_1 region
Also takes the rebuild snapshot
2
Spawns
Stand on each start pad:
/oa setup duel_1 spawn
Optional: lobby and spectator spawn.
/oa setup duel_1 lobby
Players are spread over the pads
3
Enable
/oa setup duel_1 finish
Checks the requirements and opens the arena.
Players join with:
/oa join duel_1
Or a menu, a sign, an NPC
Something missing? /oa doctor lists every gap with a clickable fix. The same steps are a book: /oa guide start
